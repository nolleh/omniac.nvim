# Agent logos

SVG assets from [agentic.nvim](https://github.com/carlos-algms/agentic.nvim/tree/4750d6ce4298b3018dd67f975a1457afbeeaa09f/.github/assets/images), pinned to `4750d6ce4298b3018dd67f975a1457afbeeaa09f`.

The upstream MIT license is preserved in [LICENSE.agentic.nvim](LICENSE.agentic.nvim). Brand names and logos belong to their respective owners.

The README uses PNG derivatives on a white background with plain Markdown image links, avoiding SVG and HTML `<picture>` rendering differences between Markdown viewers. The original SVGs, including light variants, are retained as sources.

PNGs were rendered with macOS Quick Look, then resized to 96 × 96 with ImageMagick. Quick Look handles the compact SVG path notation used by these source assets.

`agents.png` is a single transparent 3 × 2 grid for consistent alignment across Markdown viewers. Each logo is trimmed to its visible bounds, fitted inside 64 × 64, and centered on a 96 × 96 white tile. Labels share the same baseline and 200-pixel column width.
